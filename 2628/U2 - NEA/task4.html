Part (b): Multilevel Computer Game Development [25 Marks]

Note: This center focuses exclusively on the Computer Game path.

Create a multilevel computer game reflecting your chosen design option using scripting languages to control behavior.

  • Game Features required:
    • Scripting-based logic controlling game behavior.
    • Custom/animated sprites, game characters, objects, and environments.
    • Sound effects and background music to enhance gameplay.
    • Intuitive, interactive, and engaging user interface.
  • Technical Range: Demonstrate basic, medium, and complex game development techniques (e.g., scoring system, health system, animated backgrounds, scripting movement/collisions).

Required Evidence

  • Exported website files (HTML, CSS, JS) in hostable format.
  • Exported standalone computer game application downloadable from your website.
  • Annotated screenshot evidence or video screen recording explaining applied development skills.
